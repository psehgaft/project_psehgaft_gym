# project_psehgaft_gym

Rutinas diarias de gimnasio de Heber, publicadas como pósters SVG
listos para abrir en el navegador o imprimir.

## Contenido

- `rutinas psehgaft/` — pósters de rutina en formato SVG, uno por día,
  nombrados por fecha y grupo muscular. Por ejemplo:
  - `2026-10-12-lunes-pierna-gluteo-hombre.svg` — rutina de lunes de
    pierna y glúteo (versión hombre).
  - `2026-10-12-lunes-pierna-gluteo-mujer.svg` — misma rutina
    (versión mujer).

## Uso

Abre cualquier archivo `.svg` de `rutinas psehgaft/` en el navegador
para ver la rutina del día, o imprímelo para llevarlo al gimnasio.
Cada póster nuevo se agrega con su fecha en el nombre del archivo.
